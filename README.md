**TrendsForYou**

       - is a modern React-based e-commerce web app focused on simplicity, dynamic visuals, and smooth user interaction.


It delivers a clean, intuitive shopping experience with smart ad displays and visually organized product sections.

**Key Highlights**

1) Dynamic Ad Carousel – Automatically rotates ads at set time intervals, keeping the interface engaging.

2) Timed Ad Loading – New ads load dynamically after a short delay to mimic real-time updates.

3) Neatly Organized Card Layouts – Products are displayed in compact, responsive grids for easy browsing.

4) Modular Component Design – Each feature (Hero, Cart, Filter, Payment, etc.) is isolated for scalability and maintainability.

5) Minimal UI, Maximum Clarity – Clean styling using plain CSS, focusing on readability and layout balance.

6) Seamless Navigation Flow – Smooth transitions across pages like Home, Deals, Combos, Orders, and Payment.



**Built With**

  **React.js –         Component-driven front-end**

  **HTML5 & CSS3 –     Structure and styling**

  **JavaScript (ES6) – App logic and dynamic features**



**Quick guide**

# Install dependencies
npm install

# Run locally
npm start

# Build for production
npm run build
